# Crit 7: The ANU system I wish existed

## What was the breakthrough that moved the work forward?

Handing the design review to agents that each had one job.

After a few rounds of my own feedback the site worked, but it still felt crowded, and I was struggling to say why. So I sent a UI/UX agent through it with a single task: find where a student would get lost and write it up as a report. Claude read that report and rebuilt the pages around it, which is where the course boxes and the one status box at the top of each course came from. Then a product design agent looked at the new version and wrote a second report on the visual language, and that went back to Claude too.

Each agent only had to think about one thing, so its report was specific enough to act on. My part became reading the reports, deciding what to keep and what to skip, and checking the result on my phone. That was much faster than trying to describe a good design myself from a blank page.

## What did this work change about who I want to be as a software developer?

It made me want to be someone who builds things worth reusing.

I leaned heavily on my assignment 2 work this week. The harness came across in the same shape, and because this is also a university website, a good chunk of the UI did too. When Claude drifted into colours of its own, I only had to point it back at A2 and have it measure the real values. The time I spent getting A2 right paid for itself here.

The calls that mattered were still mine, though. No agent flagged that an open sign-up page would let anyone claim a uni ID and read that student's results. I noticed it and removed it. I want to keep building foundations I can reuse, and keep reading closely enough to catch what the agents miss.
